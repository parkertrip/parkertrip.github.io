How to install Sloth Web 3.0

Pick your computer. You need the matching installer file next to this page (or in Downloads).

Mac — keep the .sh file

installer_mac.sh is the real installer. Do not double-click it in Finder — that opens TextEdit. Run it in Terminal (below), or send your friend the one-liner so they never download a file.

Mac

Apple · macOS · installer_mac.sh

Open Terminal (Spotlight → Terminal) and paste:

chmod +x ~/Downloads/installer_mac.sh
~/Downloads/installer_mac.sh

If the file is not in Downloads, drag it onto the Terminal window to fill in the path.

Or skip the file entirely (best for friends):

bash -c "$(curl -fsSL https://raw.githubusercontent.com/parkertripoli-wq/sloth-web/main/installer_mac.sh)"

When it finishes:

  • New Terminal window, type sloth-web, or
  • Open Sloth Web in your Applications folder (user Applications).

Windows

Microsoft · Windows 10 / 11

File to use: installer_windows.bat

  1. Save it to Downloads. Do not open it in Notepad.
  2. Double-click installer_windows.bat.
  3. If SmartScreen appears: More info → Run anyway.
  4. If it asks to install Python, check Add python.exe to PATH.
  5. Wait until it says installed. Press any key to close.

When it finishes:

  • Desktop shortcut Sloth Web, or Start Menu → Sloth Web
  • Or Command Prompt: python %USERPROFILE%\SlothWeb\SlothWeb.py

Linux

Ubuntu · Debian · Fedora · Arch and similar

File to use: installer_linux.sh

  1. Open a terminal in the folder where you saved the file (often Downloads).
  2. Run:
chmod +x installer_linux.sh
./installer_linux.sh

It may ask for your password (sudo) to install Python / Qt libraries.

When it finishes:

  • sloth-web in a terminal (if ~/.local/bin is on PATH)
  • or python3 ~/SlothWeb/SlothWeb.py
  • or the desktop / app-menu icon

Already have Python?

Skip the installer. Save SlothWeb-3.0.py then:

python -m pip install PyQt6 PyQt6-WebEngine requests
python SlothWeb-3.0.py

On Mac/Linux use python3 if python is not found.

If something fails

  • TextEdit / Notepad opened — you opened the script as a document. Use Terminal / double-click .bat / run chmod +x as above.
  • Permission denied on Mac/Linux — you skipped chmod +x.
  • PyQt / QtWebEngine missing — the installer should pip-install PyQt6. Re-run it, or run the pip line in the previous section.
  • python is not recognized (Windows) — install Python and tick Add to PATH, then open a new Command Prompt and run the installer again.
