Troubleshooting

Python Not Found: Ensure Python 3.13.7 is installed and added to PATH. Re-run installer as administrator if needed.

Dependencies Fail: Check internet connection and run:

python -m ensurepip --upgrade
python -m pip install --upgrade pip

Shortcuts Not Working: Run installer as Administrator or recreate manually using bwsr.py path.
